# Design Audit: Meridian Agency Reference applied to SourceFirewall
## 1. Central Visual Concept: "Editorial Security." High-end, luxury agency aesthetic.
## 2. Composition: Ultra-wide, generous whitespace (120px+ padding). Asymmetric grids. Whisper-thin vertical/horizontal dividers. No cards or boxes.
## 3. Typography: `Instrument Serif` set massively large with tight negative tracking. `JetBrains Mono` set tiny, uppercase, with extreme wide tracking. `Inter` for body.
## 4. Color & Surface: Deep warm obsidian `#09090B`. Text in warm ivory `#F4F1EA` and muted stone `#8F8E8A`. Whisper-thin charcoal borders `#1C1C1F`. Status accents: pure ivory (`CLEARED`), muted terracotta `#c25e4a` (`QUARANTINED`). 
## 5. Interaction: No bouncy spring physics. Slow, cinematic crossfades.
